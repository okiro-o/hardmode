# CS2 Roulette — быстрый гайд

## 1. Установка (один раз, 5 минут)

1. Поставь Python 3.11+ с <https://www.python.org/downloads/windows/>. В установщике
   обязательно отметь **«Add python.exe to PATH»**.
2. Скопируй папку с программой куда удобно (например `D:\cs2-roulette`).
3. Дважды кликни **`run.bat`**. Первый запуск скачает зависимости (1–2 минуты), потом в
   браузере откроется панель `http://127.0.0.1:17890/`.

Окно консоли должно оставаться открытым, пока пользуешься программой. Закрыл окно — программа
остановилась. Повторный запуск `run.bat` просто откроет панель, если программа уже работает.

## 2. Подключение к CS2 (один раз)

1. В панели, раздел **«Подключение к CS2 (GSI)»**, нажми **«Установить конфиг в CS2»**.
   Папка Steam находится автоматически. Если не нашлась, нажми «Скачать конфиг» и положи
   файл в `Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\`.
2. **Перезапусти CS2** (конфиг читается только при старте игры).
3. Проверка: в главном меню игры чип **GSI** в шапке панели становится зелёным.

Это официальная функция игры: CS2 сама отправляет состояние (килы, оружие в руках, сторона)
программе на этот же компьютер. Ничего не внедряется в игру, для VAC безопасно.

## 3. OBS (один раз)

1. Источники → **+** → **Браузер**.
2. Адрес: `http://127.0.0.1:17890/overlay/weapons`, ширина `1920`, высота `1080`.
3. Галочки **«Выключать источник, когда не виден»** и **«Обновлять браузер при активации
   сцены»** оставь **выключенными**.
4. Фон прозрачный сам по себе. Переместить полоску в нужное место можно мышкой прямо в OBS
   (или выравниванием в настройках панели).

Опционально второй источник с полным лоадаутом для предматчевой паузы:
`http://127.0.0.1:17890/overlay/loadout`. Он показывает ту сторону, что выбрана вкладкой T/CT в
разделе «Лоадаут» панели (в матче переключается сам вслед за стороной); `?side=both` покажет обе.

## 4. Перед матчем

1. Раздел **«Лоадаут»** → **«🎲 Сгенерировать весь»**.
2. Выстави этот лоадаут в игре (меню Loadout). Клик по любому оружию в панели заменяет его
   на другое случайное, если что-то совсем не хочется. «Только T» / «Только CT» перегенерируют
   одну сторону.
3. Кнопка **«Копировать текстом»** скопирует список, если хочешь кинуть его в чат.

## 5. Во время матча

| Действие | Как |
|---|---|
| Начать гонку | **«▶ Старт»** в панели или хоткей **F9** в игре |
| Килл назначенным оружием | ничего не делать, оружие переключится само |
| Следующее оружие вручную | **F9** (кнопка «Следующее») |
| Перекрутить текущее без зачёта | **F8** (кнопка «Перекрутить») |
| Отменить последнее действие | **F7** (кнопка «Отмена») |
| Крутить DPI вручную | **F6** (кнопка «Крутить») |
| Перерыв, таймаут | **«⏸ Пауза»**, потом «▶ Продолжить» или F9 |
| Начать заново | **«⟲ Сброс»** |

Что показывает виджет: текущее оружие крупно, два следующих мельче, счётчик пройденных.
Когда в руках именно назначенное оружие, его силуэт красится в цвет подсветки (настраивается,
по умолчанию красный). Вспышка — килл засчитан, дрожание — килл не тем оружием.

Сторона (T/CT) определяется из игры автоматически, после смены половин очередь перестраивается
под новую сторону. Кнопки T/CT в шапке раздела — ручное переключение на всякий случай.

**Не жми F9 сразу после килла**: оружие уже переключилось, повторное нажатие в течение 1,5 с
игнорируется специально, чтобы не проскочить оружие.

## 6. Настройки, которые стоит знать

Панель разделена на вкладки: **Оружие** (гонка, лоадаут, её настройки и виджет), **DPI**
(рулетка DPI, мышь, её виджет) и **Общее** (подключение к CS2, хоткеи, все цвета в одном
месте, ссылки для OBS).

- **Автопереход после килла**: «только назначенным оружием» (по умолчанию), «любой килл»
  (ножом, гранатой тоже считается), «выключен» (только кнопки/хоткеи).
- **Киллов на оружие**: сколько киллов нужно, чтобы оружие считалось пройденным.
- **Порядок выпадения**: «мешок» (без повторов, пока не пройдёшь всё) или «чистый рандом».
- **Что участвует в рулетке**: стартовый пистолет, нож, Zeus — три отдельных переключателя.
- **Виджет**: масштаб, горизонтально/вертикально, подписи названий (вкладка «Оружие»); цвета
  силуэтов, акцента, подсветки «в руках» и сегмента «мой DPI» — вкладка «Общее → Цвета».
- Хоткеи можно переназначить: `F9`, `ctrl+alt+K`, `numpad+`, `F13`… Клавиша перехватывается
  глобально, игра её не увидит, поэтому выбирай незанятую в CS2.

## 7. Если что-то не так

- **Чип GSI серый / «не подключено».** Конфиг не установлен или CS2 не перезапущена. Если
  чип красный «токен не совпадает», нажми «Установить конфиг в CS2» и перезапусти игру.
- **Хоткеи не работают в игре, но работают на рабочем столе.** Steam или CS2 запущены от
  имени администратора. Либо запускай их обычно, либо `run.bat` тоже от администратора.
  Панель покажет предупреждение.
- **Виджет пустой.** Сессия не запущена (нажми Старт) или OBS смотрит на другой порт.
  Проверка: открой адрес виджета в обычном браузере с `?bg=222222` в конце.
- **Окно консоли закрылось с ошибкой.** Текст ошибки остаётся в окне до нажатия клавиши.
  Самая частая причина: порт 17890 занят другой программой; смени `port` в `data\settings.json`.
- **Всё сбросить.** Закрой программу и удали папку `data\` (лоадаут и настройки пропадут).

## 8. DPI-рулетка

1. В G HUB у мыши выключи «On-Board Memory Mode» (иначе сенсор не принимает DPI) и, желательно,
   закрепи профиль: Settings → Persistent Profile. Это нужно, чтобы G HUB не возвращал свой DPI
   при alt-tab.
2. В панели, раздел **«DPI-рулетка»** → **«Проверить мышь»**. Должно появиться «PRO X 2»,
   режим host и текущий DPI. Если написано ONBOARD — нажми «Host-режим».
3. Введи «Мой обычный DPI» (чтобы вернуть его кнопкой «Вернуть мой DPI» после стрима) и
   диапазон колеса (по умолчанию 800–3200, шаг 100).
4. OBS → источник «Браузер» `http://127.0.0.1:17890/overlay/dpi`, 600×750.
5. Дальше колесо крутится само после каждой смерти (в разминке не крутится) или по хоткею **F6**.
   DPI применяется, когда колесо остановилось (можно переключить на «сразу»).
6. На виджете колесо появляется только на время кручения, затем исчезает, а итоговое число
   остаётся до следующей смерти. Сегмент с твоим обычным DPI (настройка «Мой обычный DPI»)
   выделен отдельным цветом, число при выпадении на него тоже красится этим цветом. Режим «колесо всегда видно» есть в настройках.

Проверить без игры: кнопка «Симулировать смерть». Проверить без мыши: «Управление мышью →
имитация».

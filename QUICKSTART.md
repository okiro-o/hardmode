# Hardmode — справка

Hardmode (раньше CS2 Roulette): случайный лоадаут с гонкой вооружений и случайный DPI после каждой смерти. Разделы панели в меню слева: **Startup** (чек-лист), **Оружие** (гонка и зрительская очередь), **Лоадаут**, **DPI** (колесо и зрители), **Вид** (виджеты OBS, блоки поверх игры, цвета), **Донаты**, **Статистика**, **Общее** (CS2, чат, разное), **Справка**.

## Установка

1. Поставь Python 3.11–3.13 с <https://www.python.org/downloads/windows/>, в установщике отметь **Add python.exe to PATH**.
2. Распакуй папку с программой куда удобно.
3. Запусти **`run.bat`**. Первый запуск ставит зависимости (1–2 минуты), дальше программа уходит в трей (иконка рядом с часами) и открывает панель `http://127.0.0.1:17890/`.

Трей: двойной клик открывает панель; в меню «Автозапуск с Windows», «Открыть папку данных», «Выход». Лог: `data\app.log`. Запуск с консолью для отладки: `run-console.bat`.

**Сборка в exe.** Один раз запусти `build.bat`: появится папка `dist\hardmode` с `hardmode.exe`, Python на ПК больше не нужен. SmartScreen при первом запуске: «Подробнее» → «Выполнить в любом случае». Консольный режим exe: `hardmode.exe --console`.

## Обновление

Настройки, состояние гонки и лог лежат в папке `data\` рядом с программой: для запуска через `run.bat` это
`data\` в корне репозитория, для exe это `dist\hardmode\data\`. Обновление их не трогает.

- **Запуск через run.bat**: трей → «Выход», затем в папке репозитория `git pull`, затем снова `run.bat`.
  Если в обновлении поменялись зависимости, `run.bat` доставит их сам.
- **Exe**: `git pull`, затем `build.bat`. Папка `data\` рядом с exe сохраняется при пересборке.
- Конфиг GSI в папке CS2 переустанавливать нужно только когда об этом сказано в описании версии (кнопка
  «Установить конфиг в CS2» и перезапуск игры).
- Полный сброс: закрыть программу и удалить папку `data\`.

## Startup

Вкладка **Startup** — живой чек-лист. Каждый пункт проверяется сам и показывает, что сделать: данные из CS2, лоадаут, виджеты в OBS, мышь, колесо, чат, награды. Кнопки действий прямо в пунктах. При первом запуске панель открывается на ней, пока обязательные пункты не станут зелёными.

## CS2: данные из игры

1. **Общее → Подключение к CS2** → «Установить конфиг в CS2». Папка Steam находится сама; если нет — «Дополнительно → Скачать конфиг» и положить файл в `Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\`.
2. Перезапусти CS2: конфиг читается только при старте игры.
3. В главном меню игры чип **GSI** в шапке становится зелёным и показывает твой ник.

Это официальная функция игры (Game State Integration): CS2 сама отправляет состояние — килы, оружие в руках, сторону, смерти — программе на этом же компьютере. В игру ничего не внедряется, ввод ей не отправляется. Безопасно для VAC.

## OBS

Источники → **+** → **Браузер** → адрес виджета и размер. Галочки «Выключать источник, когда не виден» и «Обновлять браузер при активации сцены» — выключены. Фон прозрачный сам по себе.

Ссылки и точный размер под текущие настройки показаны на вкладке **Вид** рядом с каждым виджетом. Источник такого размера вмещает виджет целиком, его можно двигать куда угодно. Значения по умолчанию:

| Виджет | Адрес | Размер |
|---|---|---|
| Оружие, горизонтально | `/overlay/weapons` | 891×188, с подписями 891×230 |
| Оружие, вертикально | `/overlay/weapons` | 424×379, с подписями 424×465 |
| Лоадаут, строки | `/overlay/loadout` | 830×376, обе стороны 830×744 |
| Лоадаут, колонки как в игре | `/overlay/loadout` | 410×444, обе стороны 812×444 |
| Колесо DPI | `/overlay/dpi` | 600×750 |
| Зрительская очередь | `/overlay/requests` | 420×416 (5 строк) |

Адрес полностью: `http://127.0.0.1:17890` + путь. Приложение видит, подключён ли виджет именно из OBS: это отражается на вкладке Startup.

**Если OBS запущен раньше приложения**, страницы виджетов в нём не загружаются, и сам OBS их больше не перезагружает: источники есть, но пустые. Вручную это лечится в OBS: правый клик по источнику → «Обновить». Чтобы приложение делало это само при каждом запуске:

1. В OBS открой **Сервис → Настройки сервера WebSocket**, включи «Включить сервер WebSocket». Нажми «Показать сведения о подключении» и скопируй пароль.
2. В Hardmode на вкладке **Вид** в блоке «OBS: перезагрузка виджетов» вставь пароль, «Сохранить», включи «Обновлять виджеты в OBS при запуске приложения». Порт по умолчанию 4455, как в OBS.
3. «Обновить виджеты в OBS сейчас» проверяет подключение: ниже появится, сколько источников обновлено.

Обновляются только источники-браузеры с адресом Hardmode, остальные (алерты и прочее) не трогаются. Если приложение запущено раньше OBS, ничего делать не нужно: виджеты загрузятся сами. Пароль хранится только в `data\settings.json`.

## Лоадаут

1. Вкладка **Лоадаут** → «🎲 Сгенерировать» (или «только T» / «только CT»).
2. Выстави этот лоадаут в игре (меню Loadout).
3. Оружие разложено как на экране лоадаута в CS2: колонки «Пистолеты» (стартовый первым), «Мид-тир», «Винтовки». Клик по оружию в панели открывает выбор: конкретное другое оружие или случайное из оставшихся. Так можно собрать лоадаут вручную.

Правила CS2 соблюдаются: 1 стартовый пистолет (T: Glock; CT: USP-S или P2000), 4 пистолета, 5 мид-тир, 5 винтовок на сторону. Вкладка T/CT переключает и виджет лоадаута в OBS; в матче он сам следует за стороной.

## Гонка вооружений

| Действие | Как |
|---|---|
| Начать | «▶ Старт» (блок «Сессия») |
| Килл назначенным оружием | ничего: оружие переключится само |
| Следующее оружие вручную | «Следующее» (блок «Оружие») |
| Перекрутить текущее без зачёта | «Перекрутить» |
| Перерыв | «⏸ Пауза», потом «▶ Продолжить» |
| Начать заново | «⟲ Сброс» |

Виджет: текущее оружие крупно, следующие мельче, счётчик пройденных. Когда в руках именно назначенное оружие, силуэт красится в цвет подсветки. Вспышка — килл засчитан, дрожание — килл не тем оружием.

Сторона определяется из игры; после смены половин очередь перестраивается. Кнопки T/CT в заголовке блока — ручное переключение.

Настройки (**Оружие → Настройки гонки**): автопереход после килла (только назначенным / любой килл / выключен) и что участвует (стартовый пистолет, нож, Zeus). В «Дополнительно»: киллов на оружие, порядок выпадения (мешок или рандом), число следующих, определение стороны, стартовый пистолет CT. Внешний вид виджета: вкладка **Вид**.

## DPI-рулетка

1. В G HUB у мыши выключи **On-Board Memory Mode** и закрепи профиль: Settings → Persistent Profile (иначе G HUB может возвращать свой DPI при alt-tab).
2. **DPI → Мышь → «Проверить»**: должно показать имя мыши, host-режим и текущий DPI. Если ONBOARD — кнопка «Host-режим».
3. Укажи «Мой обычный DPI» в настройках DPI (кнопка «Вернуть мой DPI» ставит его обратно) и диапазон в блоке «Значения колеса».
4. OBS → источник «Браузер» `/overlay/dpi`, 600×750.

Колесо крутится само после каждой смерти, по желанию и после каждого килла (переключатели в настройках DPI, можно включить оба; в разминке не крутится) или по кнопке «Крутить». «Пауза между кручениями» не даёт колесу крутиться чаще раза в несколько секунд, например при мультикилле. Если на колесе осталось одно значение, кручения нет: число просто меняется на виджете. DPI применяется, когда колесо остановилось; для Deathmatch в настройках DPI есть режим «сразу после смерти»: новое значение ставится мгновенно, а колесо на виджете докручивается уже к нему. На виджете колесо видно только во время кручения, потом остаётся число до следующей смерти. Твой обычный DPI всегда есть на колесе, выделен своим цветом, в режиме «мешок» не исчезает и в чередовании цветов остальных сегментов не участвует.

Host-режим: у мышей Logitech два режима — onboard (мышь живёт по профилям в своей памяти, DPI снаружи менять нельзя) и host (управляет софт на ПК). G HUB держит мышь в host, когда On-Board Memory Mode выключен. Кнопки мыши в host-режиме работают как обычно.

Поддерживаются мыши Logitech с HID++: Superlight 2, G502 X, G Pro Wireless, G304/G305, G403 и другие. Без мыши можно проверять всё в режиме «Управление мышью → имитация».

## Статистика

Вкладка **Статистика** копит сводку с начала стрима и переживает перезапуск программы:

- **DPI**: сколько раз выпало каждое значение, сколько киллов на одно выпадение, сколько с ним сделано киллов и смертей, сколько раундов прожито целиком с ним (без смены DPI внутри раунда) и сколько времени оно стояло в живых раундах.
- **Оружие**, независимо от гонки: сколько раз куплено, сколько подобрано с пола или у тиммейта, киллов, хедшотов, смертей с ним в руках. Урона по оружию нет: игра сообщает только общий урон за раунд, а не чем он нанесён. Общий урон есть в сводке, по картам и по DPI.
- **Гранаты** отдельно от оружия: куплено, подобрано, брошено, киллов. «Брошено» считается по исчезновению гранаты из инвентаря живого игрока, выброс кнопкой тоже попадёт в счёт.
- **Карты**: матчей, раундов, K/D/A, урон, ADR (урон на раунд), процент HS. Ассисты берутся из статистики матча. Покупка отличается от подбора по тому, уменьшились ли деньги в тот же момент; стартовый пистолет и нож после респауна не считаются.
- Сводка: раунды, киллы, смерти, ассисты, K/D, процент HS, урон, ADR, лучший раунд, число кручений DPI.
- Любую колонку можно сортировать кликом по заголовку, второй клик меняет направление. «Сброс» обнуляет всё, «CSV» выгружает таблицы. Разминка, нож, аптечка и бомба в статистику не попадают.

## Поверх игры

Чтобы не искать число на втором мониторе, приложение рисует текущий DPI, текущее оружие и зрительскую очередь прямо поверх CS2: маленькие окна с прозрачным фоном, которые не ловят клики и не забирают фокус. В игру ничего не внедряется.

1. В CS2 поставь режим экрана **Fullscreen Windowed** (полноэкранный в окне). В обычном Fullscreen Windows не показывает чужие окна поверх игры, это ограничение системы. На Windows 10/11 с включённой «Оптимизацией для оконных игр» разницы в FPS и задержке нет.
2. **Вид → Поверх игры: оружие**, **DPI** и **зрительская очередь**: угол экрана, отступы, масштаб, непрозрачность. Режим «после смены» показывает блок на несколько секунд после каждого изменения, «всегда» держит его на экране постоянно. Картинка рядом с кнопкой показывает, как блок выглядит.
3. «Показать поверх игры на 5 с» выводит блок на экран прямо сейчас, чтобы подобрать место. Если гонка или DPI ещё не запущены, а очередь пуста, показывается пример.

**Блок зрительской очереди** показывает первые заявки: номер, силуэт, оружие и кто заказал. Первая заявка подсвечена. Заявки, которые сейчас не выполнить, приглушены и подписаны почему: «в лоадауте T» или «не в лоадауте». Остальные свёрнуты в «+ ещё N». По умолчанию он виден всё время, пока в очереди есть заявки, и пропадает, когда очередь пуста. Режим «после изменения» показывает его на несколько секунд после каждой новой или закрытой заявки. Число строк (по умолчанию 3) и подпись «кто заказал» настраиваются. Стоит по умолчанию слева сверху под блоком оружия.

В OBS эти блоки не попадают при захвате игры (Game Capture). При захвате экрана они будут видны зрителям, тогда либо выключи их, либо используй захват игры.

## Значения колеса и зрители

- **Значения колеса** (вкладка DPI): диапазон мин–макс–шаг можно выключить и добавлять свои числа. Всё округляется к сетке сенсора (шаг 10 в диапазоне 1000–2000, шаг 20 в 2000–5000).
- **Круг**: выпавшее значение уходит с колеса, пока не выпадут все, затем круг начинается заново. «⟲ Новый круг» возвращает всё сразу. Режим «остаются» отключает это.
- **Зрители за баллы канала**: нужен вход в Twitch (глава «Twitch-аккаунт»). В блоке «DPI от зрителей» включи переключатель и нажми «Создать в Twitch»: в канале появится награда «Добавить DPI в рулетку» с обязательным текстом. Зритель пишет число, оно округляется до сотни (666 → 700, 228 → 200 и отказ «вне диапазона»). Одно и то же значение можно добавить несколько раз, в том числе разным зрителям: на колесе это один сегмент, но шире, и шанс выпадения выше. В режиме «мешок» выпавшее зрительское значение уходит с колеса, в режиме «рандом» остаётся. Лимиты: диапазон, число значений всего и на зрителя. Без баллов работает чат-команда, например `!dpi 1600` (в «Дополнительно»).
- В чат уходит подтверждение («✅ Alice добавил 1600 DPI на колесо») или отказ («❌ Alice: вне диапазона 400–6400. Баллы вернул»), отказ не чаще раза в 30 с на зрителя. Баллы за отказ возвращаются сами. Сообщения включаются и выключаются в настройках чата на вкладке «Общее», кулдаун и лимиты самой награды ставятся в Twitch.

**Зрительская очередь** живёт отдельно от гонки: зритель может заказать оружие не из твоего лоадаута, ты выполняешь заявку, когда получится (подобрал в раунде, поставил в лоадаут на следующий матч). Очередь делится на три части, внутри каждой заявки идут в порядке поступления. Наверху то, что можно выполнить прямо сейчас: оружие есть в лоадауте стороны, за которую ты играешь. Дальше оружие из лоадаута другой стороны с пометкой, например «в лоадауте T» у Tec-9, пока ты за CT: после смены сторон оно поднимется само. В самом конце оружие, которого нет в лоадауте, с пометкой «не в лоадауте». Сторона берётся из игры. Когда меняется сторона или лоадаут, очередь переставляется сама. Пока лоадаут не сгенерирован, наверху то, что твоя сторона вообще может купить. Нож и Zeus можно заказать, только если они включены в настройках гонки («Что участвует в рулетке»): иначе бот отвечает «Нож сейчас не принимается». Килл заказанным оружием сам закрывает самую старую заявку на него. Кнопки у заявки: «✓» выполнено, «↑» выше (только внутри своей части очереди), «×» убрать; у нераспознанной — «Выбрать» оружие вручную. Гонку можно не запускать и играть по очереди зрителей.

**Оружие за баллы канала.** Зрители могут заказывать оружие и без доната, наградой «Добавить оружие в очередь». Нужен вход в Twitch: под очередью раскрой «Twitch: оружие за баллы и команда очереди», включи «Оружие за баллы канала» и нажми «Создать в Twitch». Зритель пишет в награде оружие («AWP», «калаш», «плётку»). Распознанное встаёт в очередь с пометкой «баллы», в чат уходит «🎯 Alice заказал AWP, №2 в очереди». Нераспознанное в очередь не попадает: баллы возвращаются сами, в чат уходит отказ с примером.

**Виджет очереди для OBS** (`/overlay/requests`, настройки на вкладке «Вид»): номер, силуэт, оружие и имя зрителя, первая заявка подсвечена, лишние сворачиваются в «+ ещё N». Новая заявка въезжает, выполненная на секунду загорается зелёной галочкой. Пустая очередь не рисуется. Сумма доната показывается по переключателю.

**Команда `!очередь`**: приложение отвечает в чате от твоего аккаунта, где заявки зрителя («твои заявки: AWP — №2»), или коротко перечисляет очередь. Заявки ищутся по имени из доната или Twitch, так что если донатер подписался не своим ником, свою заявку он не найдёт. Работает, когда выполнен вход в Twitch и включены уведомления в чат; команда меняется или выключается в блоке «Twitch: оружие за баллы и команда очереди» под очередью. Один ответ одному зрителю раз в 15 секунд.

**Псевдонимы оружия.** Оружие ищется в тексте доната по встроенному словарю: официальные названия, латиница и кириллица, сленг («крокодил» — XM1014, «морковка» — MP5-SD, «калаш» — AK-47). Регистр, дефисы, пробелы и раскладка не важны: «АК-47», «ак 47», «ak47» одно и то же. «Плётка» означает и G3SG1, и SCAR-20: в очередь встаёт ствол твоей текущей стороны (T — G3SG1, CT — SCAR-20). Слово со звёздочкой ловит любые окончания («калаш*» → «калашом»). Свои псевдонимы добавляются строками «алиас = оружие»; поле «Проверить текст» показывает, что найдётся в сообщении. Полный словарь открывается кнопкой «Встроенный словарь».

## Twitch-аккаунт

Вход в Twitch нужен для трёх вещей: **награды за баллы** («Добавить DPI в рулетку», «Добавить оружие в очередь»), **сообщения в чат от твоего имени** и **чат-команды** (`!очередь`, `!dpi`). Награды создаёт само приложение: Twitch даёт вернуть баллы только за такие награды, поэтому награды, сделанные руками, приложение не обрабатывает. Если они остались с прежних версий, удали их в Twitch.

**Вход.** Кнопка **«Войти через Twitch»** справа сверху, она видна на любой вкладке. Откроется страница Twitch «Активируйте устройство» с уже вписанным кодом: так Twitch называет вход для программ, а код он подставил сам. Сверь его с кодом во всплывающем окне Hardmode, нажми «Активировать», затем «Разрешить». Регистрировать своё приложение в Twitch не нужно. Вход держится, пока приложение запускается хотя бы раз в 30 дней, иначе нажми «Войти» ещё раз. После входа на кнопке твой ник, по клику на неё есть «Выйти».

**Награды.** «Создать в Twitch» в блоке «DPI от зрителей» (вкладка «DPI») и под очередью на вкладке «Оружие». Награда создаётся с обязательным текстом; стоимость задаётся при создании. Дальше:
- отказ (оружие не распознано, нож выключен, число вне диапазона, функция выключена в приложении) — баллы возвращаются сами, в чат уходит причина и «Баллы вернул»;
- оружие принято — заявка ждёт в очереди и в очереди наград Twitch; «✓» или килл этим оружием отмечают её выполненной, «×» возвращает баллы;
- DPI принят — отмечается выполненным сразу;
- выкупы, пришедшие, пока приложение было выключено больше 10 минут, при запуске возвращаются.

В Twitch у этих наград можно менять стоимость, кулдаун, лимиты, иконку и цвет. Не включай «Пропускать очередь запросов» и не выключай «Требовать ввод текста»: иначе приложение не увидит выкуп или не сможет вернуть баллы. «Удалить из Twitch» убирает награду из канала.

**Чат.** Вкладка «Общее» → «Чат Twitch»: включи уведомления, проверь «Отправить тест в чат» и выбери события: старт гонки, новое оружие, новый DPI, добавление зрителя, отказ зрителю, что сделал донат, оружие за баллы в очереди, выполненная заявка. Тексты редактируются; подстановки `{weapon}` `{completed}` `{kills}` `{side}` `{dpi}` `{user}` `{reason}` `{result}` `{position}`. Серии быстрых событий схлопываются в последнее сообщение, между сообщениями пауза минимум 2 с. Команды чата читаются из твоего канала, логин канала берётся из входа.

**Безопасность.** Ключи входа хранятся только у тебя на компьютере в `data\twitch.json`, панель их не показывает, и в git папка `data` не попадает. «Выйти» отзывает доступ. Отозвать его можно и в самом Twitch: Настройки → Подключения.

## Если что-то не так

- **GSI «не подключено»**: конфиг не установлен или CS2 не перезапущена. **«старый токен»**: нажми «Установить конфиг в CS2» и перезапусти игру.
- **Виджет пустой**: сессия не запущена или в OBS другой адрес. Для проверки открой адрес в браузере с `?bg=222222`.
- **Мышь не найдена**: в G HUB выключен ли On-Board Memory Mode, включена ли мышь; подробности в `data\app.log`.
- **В exe пишет «В сборке нет модуля hidapi»**: при сборке модуль не попал в `dist\hardmode\_internal`. Пересобери `build.bat` на Python 3.11–3.13 и смотри на предупреждения в конце сборки.
- **Сообщения не приходят в чат**: проверь, что выполнен вход в Twitch и включены уведомления; ошибка видна под кнопкой «Отправить тест в чат» на вкладке «Общее».
- **Порт 17890 занят**: смени `port` в `data\settings.json` и переустанови конфиг CS2.
- **Сбросить всё**: закрой программу и удали папку `data\`.

## Параметры виджетов

Параметры в адресе переопределяют настройки, удобно для нескольких источников:

- `/overlay/weapons?scale=1.3&layout=vertical&labels=1&color=ffffff&counter=0&align=center`
- `/overlay/loadout?side=both&layout=columns&names=0&scale=0.8`
- `/overlay/dpi?scale=0.8&wheel=always&hide=0`
- `?bg=1b1e26` — фон для предпросмотра в обычном браузере; `?debug=1` — отладочная плашка.

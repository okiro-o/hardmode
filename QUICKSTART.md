# Hardmode — справка

Hardmode (раньше CS2 Roulette): случайный лоадаут с гонкой вооружений и случайный DPI после каждой смерти. Вкладки панели: **Startup** (чек-лист), **Оружие** (гонка и лоадаут), **DPI** (колесо и зрители), **Вид** (виджеты OBS, блоки поверх игры, цвета), **Донаты**, **Статистика**, **Общее** (CS2, чат, разное), **Справка**.

## Установка

1. Поставь Python 3.11–3.13 с <https://www.python.org/downloads/windows/>, в установщике отметь **Add python.exe to PATH**.
2. Распакуй папку с программой куда удобно.
3. Запусти **`run.bat`**. Первый запуск ставит зависимости (1–2 минуты), дальше программа уходит в трей (иконка рядом с часами) и открывает панель `http://127.0.0.1:17890/`.

Трей: двойной клик открывает панель; в меню «Автозапуск с Windows», «Открыть папку данных», «Выход». Лог: `data\app.log`. Запуск с консолью для отладки: `run-console.bat`.

**Сборка в exe.** Один раз запусти `build.bat`: появится папка `dist\hardmode` с `hardmode.exe`, Python на ПК больше не нужен. SmartScreen при первом запуске: «Подробнее» → «Выполнить в любом случае». Консольный режим exe: `hardmode.exe --console`.

## Обновление

Настройки, состояние гонки и лог лежат в папке `data\` рядом с программой: для запуска через `run.bat` это
`data\` в корне репозитория, для exe это `dist\hardmode\data\`. Обновление их не трогает.

- **Запуск через run.bat**: трей → «Выход», затем в папке репозитория `git pull`, затем снова `run.bat`.
  Если в обновлении поменялись зависимости, `run.bat` доставит их сам.
- **Exe**: `git pull`, затем `build.bat`. Папка `data\` рядом с exe сохраняется при пересборке.
- Конфиг GSI в папке CS2 переустанавливать нужно только когда об этом сказано в описании версии (кнопка
  «Установить конфиг в CS2» и перезапуск игры).
- Полный сброс: закрыть программу и удалить папку `data\`.

## Startup

Вкладка **Startup** — живой чек-лист. Каждый пункт проверяется сам и показывает, что сделать: данные из CS2, лоадаут, виджеты в OBS, мышь, колесо, чат, награды. Кнопки действий прямо в пунктах. При первом запуске панель открывается на ней, пока обязательные пункты не станут зелёными.

## CS2: данные из игры

1. **Общее → Подключение к CS2** → «Установить конфиг в CS2». Папка Steam находится сама; если нет — «Дополнительно → Скачать конфиг» и положить файл в `Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\`.
2. Перезапусти CS2: конфиг читается только при старте игры.
3. В главном меню игры чип **GSI** в шапке становится зелёным и показывает твой ник.

Это официальная функция игры (Game State Integration): CS2 сама отправляет состояние — килы, оружие в руках, сторону, смерти — программе на этом же компьютере. В игру ничего не внедряется, ввод ей не отправляется. Безопасно для VAC.

## OBS

Источники → **+** → **Браузер** → адрес виджета и размер. Галочки «Выключать источник, когда не виден» и «Обновлять браузер при активации сцены» — выключены. Фон прозрачный сам по себе.

Ссылки и точный размер под текущие настройки показаны на вкладке **Вид** рядом с каждым виджетом. Источник такого размера вмещает виджет целиком, его можно двигать куда угодно. Значения по умолчанию:

| Виджет | Адрес | Размер |
|---|---|---|
| Оружие, горизонтально | `/overlay/weapons` | 891×188, с подписями 891×230 |
| Оружие, вертикально | `/overlay/weapons` | 424×379, с подписями 424×465 |
| Лоадаут, строки | `/overlay/loadout` | 830×376, обе стороны 830×744 |
| Лоадаут, колонки как в игре | `/overlay/loadout` | 410×444, обе стороны 812×444 |
| Колесо DPI | `/overlay/dpi` | 600×750 |

Адрес полностью: `http://127.0.0.1:17890` + путь. Приложение видит, подключён ли виджет именно из OBS: это отражается на вкладке Startup.

## Лоадаут

1. **Оружие → Лоадаут** → «🎲 Сгенерировать» (или «только T» / «только CT»).
2. Выстави этот лоадаут в игре (меню Loadout).
3. Клик по оружию в панели открывает выбор: конкретное другое оружие или случайное из оставшихся. Так можно собрать лоадаут вручную.

Правила CS2 соблюдаются: 1 стартовый пистолет (T: Glock; CT: USP-S или P2000), 4 пистолета, 5 мид-тир, 5 винтовок на сторону. Вкладка T/CT переключает и виджет лоадаута в OBS; в матче он сам следует за стороной.

## Гонка вооружений

| Действие | Как |
|---|---|
| Начать | «▶ Старт» (блок «Сессия») |
| Килл назначенным оружием | ничего: оружие переключится само |
| Следующее оружие вручную | «Следующее» (блок «Оружие») |
| Перекрутить текущее без зачёта | «Перекрутить» |
| Перерыв | «⏸ Пауза», потом «▶ Продолжить» |
| Начать заново | «⟲ Сброс» |

Виджет: текущее оружие крупно, следующие мельче, счётчик пройденных. Когда в руках именно назначенное оружие, силуэт красится в цвет подсветки. Вспышка — килл засчитан, дрожание — килл не тем оружием.

Сторона определяется из игры; после смены половин очередь перестраивается. Кнопки T/CT в заголовке блока — ручное переключение.

Настройки (**Оружие → Настройки гонки**): автопереход после килла (только назначенным / любой килл / выключен) и что участвует (стартовый пистолет, нож, Zeus). В «Дополнительно»: киллов на оружие, порядок выпадения (мешок или рандом), число следующих, определение стороны, стартовый пистолет CT. Внешний вид виджета: вкладка **Вид**.

## DPI-рулетка

1. В G HUB у мыши выключи **On-Board Memory Mode** и закрепи профиль: Settings → Persistent Profile (иначе G HUB может возвращать свой DPI при alt-tab).
2. **DPI → Мышь → «Проверить»**: должно показать имя мыши, host-режим и текущий DPI. Если ONBOARD — кнопка «Host-режим».
3. Укажи «Мой обычный DPI» в настройках DPI (кнопка «Вернуть мой DPI» ставит его обратно) и диапазон в блоке «Значения колеса».
4. OBS → источник «Браузер» `/overlay/dpi`, 600×750.

Колесо крутится само после каждой смерти, по желанию и после каждого килла (переключатели в настройках DPI, можно включить оба; в разминке не крутится) или по кнопке «Крутить». «Пауза между кручениями» не даёт колесу крутиться чаще раза в несколько секунд, например при мультикилле. Если на колесе осталось одно значение, кручения нет: число просто меняется на виджете. DPI применяется, когда колесо остановилось; для Deathmatch в настройках DPI есть режим «сразу после смерти»: новое значение ставится мгновенно, а колесо на виджете докручивается уже к нему. На виджете колесо видно только во время кручения, потом остаётся число до следующей смерти. Твой обычный DPI всегда есть на колесе, выделен своим цветом, в режиме «мешок» не исчезает и в чередовании цветов остальных сегментов не участвует.

Host-режим: у мышей Logitech два режима — onboard (мышь живёт по профилям в своей памяти, DPI снаружи менять нельзя) и host (управляет софт на ПК). G HUB держит мышь в host, когда On-Board Memory Mode выключен. Кнопки мыши в host-режиме работают как обычно.

Поддерживаются мыши Logitech с HID++: Superlight 2, G502 X, G Pro Wireless, G304/G305, G403 и другие. Без мыши можно проверять всё в режиме «Управление мышью → имитация».

## Статистика

Вкладка **Статистика** копит сводку с начала стрима и переживает перезапуск программы:

- **DPI**: сколько раз выпало каждое значение, сколько киллов на одно выпадение, сколько с ним сделано киллов и смертей, сколько раундов прожито целиком с ним (без смены DPI внутри раунда) и сколько времени оно стояло в живых раундах.
- **Оружие**, независимо от гонки: сколько раз куплено, сколько подобрано с пола или у тиммейта, киллов, хедшотов, урон, смертей с ним в руках. Урон берётся из счётчика игры за раунд и приписывается оружию, которое было в руках в момент попадания; урон гранаты, взорвавшейся после переключения на пушку, уходит пушке.
- **Гранаты** отдельно от оружия: куплено, подобрано, брошено, киллов, урон. «Брошено» считается по исчезновению гранаты из инвентаря живого игрока, выброс кнопкой тоже попадёт в счёт.
- **Карты**: матчей, раундов, K/D/A, урон, ADR (урон на раунд), процент HS. Ассисты берутся из статистики матча. Покупка отличается от подбора по тому, уменьшились ли деньги в тот же момент; стартовый пистолет и нож после респауна не считаются.
- Сводка: раунды, киллы, смерти, ассисты, K/D, процент HS, урон, ADR, лучший раунд, число кручений DPI.
- Любую колонку можно сортировать кликом по заголовку, второй клик меняет направление. «Сброс» обнуляет всё, «CSV» выгружает таблицы. Разминка, нож, аптечка и бомба в статистику не попадают.

## Поверх игры

Чтобы не искать число на втором мониторе, приложение рисует текущий DPI и текущее оружие прямо поверх CS2: маленькие окна с прозрачным фоном, которые не ловят клики и не забирают фокус. В игру ничего не внедряется.

1. В CS2 поставь режим экрана **Fullscreen Windowed** (полноэкранный в окне). В обычном Fullscreen Windows не показывает чужие окна поверх игры, это ограничение системы. На Windows 10/11 с включённой «Оптимизацией для оконных игр» разницы в FPS и задержке нет.
2. **Вид → Поверх игры: оружие** и **Вид → Поверх игры: DPI**: угол экрана, отступы, масштаб, непрозрачность. Режим «после смены» показывает блок на несколько секунд после каждого изменения, «всегда» держит его на экране постоянно. Картинка рядом с кнопкой показывает, как блок выглядит.
3. «Показать поверх игры на 5 с» выводит блок на экран прямо сейчас, чтобы подобрать место. Если гонка или DPI ещё не запущены, показывается пример.

В OBS эти блоки не попадают при захвате игры (Game Capture). При захвате экрана они будут видны зрителям, тогда либо выключи их, либо используй захват игры.

## Значения колеса и зрители

- **Значения колеса** (вкладка DPI): диапазон мин–макс–шаг можно выключить и добавлять свои числа. Всё округляется к сетке сенсора (шаг 10 в диапазоне 1000–2000, шаг 20 в 2000–5000).
- **Круг**: выпавшее значение уходит с колеса, пока не выпадут все, затем круг начинается заново. «⟲ Новый круг» возвращает всё сразу. Режим «остаются» отключает это.
- **Зрители за баллы канала**: в Twitch создай награду с обязательным текстом («Добавить DPI в колесо», подсказка «число от 400 до 6400»). В блоке «Зрители добавляют DPI» включи переключатель, проверь логин канала (подставляется после «Проверить токен» SE), нажми «Определить» и выкупи награду один раз — приложение запомнит её. Число округляется до сотни (666 → 700, 228 → 200 и отказ «вне диапазона»). Одно и то же значение можно добавить несколько раз, в том числе разным зрителям: на колесе это один сегмент, но шире, и шанс выпадения выше. В режиме «мешок» выпавшее зрительское значение уходит с колеса, в режиме «рандом» остаётся. Лимиты: диапазон, число значений всего и на зрителя. Чат читается анонимно, токены не нужны. Без баллов — чат-команда, например `!dpi 1600`.
- Бот StreamElements подтверждает добавление («✅ Alice добавил 1600 DPI на колесо») и объясняет отказ («❌ Alice: вне диапазона 400–6400»), не чаще раза в 30 с на зрителя. Кулдаун и лимиты самой награды ставятся в Twitch.

## Донаты

Донаты из **DonationAlerts** и **DonatePay** приложение забирает само (DonationAlerts раз в 5 секунд, DonatePay раз в 20: чаще он не разрешает) и по правилам превращает в эффекты. Все эффекты ждут своего момента, ничего не «перекручивается» посреди раунда.

**Подключение DonationAlerts** (один раз):

1. В кабинете DonationAlerts открой раздел приложений для разработчиков (`https://www.donationalerts.com/application/clients`) и создай приложение. Название любое, в «Redirect URL» вставь адрес с вкладки **Донаты** (кнопка «Копировать»): `http://127.0.0.1:17890/donations/da/callback`.
2. Скопируй из созданного приложения его **ID** и **секрет** на вкладку «Донаты», секрет сохрани кнопкой «Сохранить».
3. «Подключить»: откроется DonationAlerts, нажми «Разрешить». Чип станет зелёным с именем аккаунта. Вкладку DonationAlerts можно закрыть.

**Подключение DonatePay**: на `donatepay.ru` войди и открой страницу API (`donatepay.ru/page/api`), там твой ключ. Вставь его, «Сохранить», «Проверить ключ». Тестовые оповещения из кабинета DonatePay учитываются только с переключателем «Учитывать тестовые оповещения».

Включи «Донаты включены». Донаты, пришедшие до первого подключения, не обрабатываются; пришедшие, пока программа была закрыта, обрабатываются, если им не больше 10 минут.

**Правила** проверяются сверху вниз, срабатывает первое подходящее: сумма в пределах «от» и «до», слово (если задано) есть в сообщении, а в сообщении есть то, что нужно действию. Действия:

| Действие | Что делает | Что ищет в сообщении |
|---|---|---|
| оружие в очередь | заявка в зрительскую очередь на вкладке «Оружие» | оружие по словарю ниже; со словом в правиле заявка создаётся и без распознанного оружия |
| следующий DPI | следующее кручение колеса встанет на это число | число, например `1600` или `1 600` |
| число на колесо | число добавляется на колесо как зрительское | число |

По умолчанию: оружие от 300 ₽, следующий DPI от 500 ₽, число на колесо от 50 ₽. Числа проверяются так же, как зрительские: округление до сотни и диапазон «Мин./макс. DPI от зрителей»; лимит «одно значение на зрителя» для донатов не действует. Если оружие или число узнано, а суммы не хватило, бот напишет в чат, от какой суммы это работает. «Тестовый донат» прогоняет сообщение через правила без денег.

**Зрительская очередь** живёт отдельно от гонки: зритель может заказать оружие не из твоего лоадаута, ты выполняешь заявку, когда получится (подобрал в раунде, поставил в лоадаут на следующий матч). Килл заказанным оружием закрывает самую старую заявку на него сам (выключается в «Выполнено недавно и настройки»). Кнопки у заявки: «✓» выполнено, «↑» выше, «×» убрать; у нераспознанной — «Выбрать» оружие вручную. Гонку можно не запускать и играть по очереди зрителей.

**Следующий DPI по донату** виден на вкладке «DPI» в списке «Следующие по донатам». Колесо крутится как обычно, но встаёт на заказанное число, на виджете подпись «заказал Имя». Несколько заказов выполняются по очереди.

**Псевдонимы оружия.** Оружие ищется в тексте доната по встроенному словарю: официальные названия, латиница и кириллица, сленг («крокодил» — XM1014, «морковка» — MP5-SD, «калаш» — AK-47). Регистр, дефисы, пробелы и раскладка не важны: «АК-47», «ак 47», «ak47» одно и то же. «Плётка» означает и G3SG1, и SCAR-20: в очередь встаёт ствол твоей текущей стороны (T — G3SG1, CT — SCAR-20). Слово со звёздочкой ловит любые окончания («калаш*» → «калашом»). Свои псевдонимы добавляются строками «алиас = оружие»; поле «Проверить текст» показывает, что найдётся в сообщении. Полный словарь открывается кнопкой «Встроенный словарь».

## Чат через StreamElements

1. streamelements.com → иконка аккаунта → свой канал → **Show secrets** → скопируй **JWT Token**. Бот SE должен быть добавлен в канал («Join channel»).
2. **Общее → Чат Twitch через StreamElements**: вставь токен → «Сохранить» → «Проверить токен» → «Отправить тест в чат». Проверка читает состояние бота (в канале / модератор / заглушен) и сама подключает бота к каналу, если его там нет.
3. Включи уведомления и выбери события: старт гонки, новое оружие, новый DPI, добавление зрителя, отказ зрителю, что сделал донат, выполненная заявка. Тексты редактируются; подстановки `{weapon}` `{completed}` `{kills}` `{side}` `{dpi}` `{user}` `{reason}` `{result}`.

**Сообщения не появляются в чате**, хотя тест пишет «принял»: StreamElements отвечает успехом и тогда, когда бот не в канале, заглушен (Bot → Mute в дашборде SE) или выключен; строка статуса под кнопками это покажет. Если с ботом всё в порядке, а сообщений нет, чат долго простаивал: Twitch прячет сообщения бота после долгой тишины. Напиши пару сообщений в чат сам, и бот снова станет виден. Чат в режиме «только фолловеры/сабы» бот-модератор обходит.

Токен хранится только в `data\settings.json` и уходит только на api.streamelements.com. Не показывай вкладку «Общее» на стриме, пока вставляешь токен. Серии быстрых событий схлопываются в последнее сообщение, между сообщениями пауза минимум 2 с.

## Если что-то не так

- **GSI «не подключено»**: конфиг не установлен или CS2 не перезапущена. **«старый токен»**: нажми «Установить конфиг в CS2» и перезапусти игру.
- **Виджет пустой**: сессия не запущена или в OBS другой адрес. Для проверки открой адрес в браузере с `?bg=222222`.
- **Мышь не найдена**: в G HUB выключен ли On-Board Memory Mode, включена ли мышь; подробности в `data\app.log`.
- **В exe пишет «В сборке нет модуля hidapi»**: при сборке модуль не попал в `dist\hardmode\_internal`. Пересобери `build.bat` на Python 3.11–3.13 и смотри на предупреждения в конце сборки.
- **Бот SE молчит**: см. раздел «Чат через StreamElements».
- **Порт 17890 занят**: смени `port` в `data\settings.json` и переустанови конфиг CS2.
- **Сбросить всё**: закрой программу и удали папку `data\`.

## Параметры виджетов

Параметры в адресе переопределяют настройки, удобно для нескольких источников:

- `/overlay/weapons?scale=1.3&layout=vertical&labels=1&color=ffffff&counter=0&align=center`
- `/overlay/loadout?side=both&layout=columns&names=0&scale=0.8`
- `/overlay/dpi?scale=0.8&wheel=always&hide=0`
- `?bg=1b1e26` — фон для предпросмотра в обычном браузере; `?debug=1` — отладочная плашка.

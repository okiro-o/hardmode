# Hardmode

Стрим-тулза для CS2 (Windows): делает игру сложнее и интерактивнее.

* **Гонка вооружений**: случайный лоадаут по правилам CS2, рулетка оружия с автопереходом по
  киллам из игры (официальный GSI), виджет-силуэты для OBS.
* **DPI-рулетка**: после каждой смерти колесо выбирает случайный DPI и ставит его на мышь
  Logitech напрямую по HID++ (рядом с G HUB). Зрители добавляют значения за баллы канала.
* **Оверлей поверх игры**, уведомления в чат через бота StreamElements, статистика стрима.

Подробная инструкция: [QUICKSTART.md](QUICKSTART.md) (она же вкладка «Справка» в панели).
Спецификация для разработки: [docs/SPEC.md](docs/SPEC.md).

## Быстрый старт

1. Python 3.11–3.13 с <https://www.python.org/downloads/windows/> («Add python.exe to PATH»).
2. `git clone https://github.com/okiro-o/hardmode.git`, затем `run.bat`: он создаст окружение,
   уйдёт в трей и откроет панель <http://127.0.0.1:17890/>. Обновление: `git pull` и снова `run.bat`.
3. Вкладка **Startup** в панели ведёт по остальному: конфиг GSI в CS2, лоадаут, источники OBS,
   мышь, чат.

`build.bat` собирает папку `dist\hardmode` с exe, Python на целевом ПК тогда не нужен.
`run-console.bat` запускает с консолью для отладки.

## Как это устроено

* Сервер слушает только `127.0.0.1`, в процесс игры ничего не внедряется и ввод ей не
  отправляется: данные идут из Game State Integration (официальный механизм Valve), DPI меняется
  командами HID++ мыши. Безопасно для VAC.
* Состояние живёт на сервере (`data\`), виджеты лишь отрисовывают снапшоты, поэтому перезагрузка
  источника в OBS ничего не теряет.
* Килл атрибутируется эвристикой: рост `round_kills` в живом раунде, оружие из предыдущего пакета,
  броски HE/молотова помечают килл спорным.

## Разработка

```bash
./run.sh --no-browser          # macOS/Linux: имитация мыши, без трея и оверлея поверх игры
.venv/bin/python -m pytest -q  # тесты
```

# CS2 Roulette

Мини-утилита для стримов по CS2 (Windows).

* Часть 1 — **гонка вооружений**: случайный лоадаут, рулетка оружия с автопереходом по
  киллам из игры и прозрачный виджет для OBS.
* Часть 2 — **DPI-рулетка**: колесо выбирает случайный DPI (по умолчанию 800–3200) после
  каждой смерти или по хоткею и применяет его к Logitech G PRO X Superlight 2 напрямую по
  HID++ (работает рядом с G HUB). Виджет-колесо для OBS.

## Быстрый старт (Windows)

1. Установите Python 3.11+ с <https://www.python.org/downloads/windows/>
   (отметьте «Add python.exe to PATH»).
2. Дважды кликните `run.bat`. При первом запуске он создаст окружение и поставит
   зависимости, затем откроет панель <http://127.0.0.1:17890/>.
3. В панели: **Подключение к CS2 → «Установить конфиг в CS2»** (папка Steam ищется
   автоматически). Перезапустите CS2 — игра начнёт слать состояние в утилиту.
4. **Лоадаут → «Сгенерировать весь»**. Выставьте его в игре (меню Loadout), клик по
   оружию в панели заменяет его на другое случайное.
5. В OBS добавьте источник **Браузер** с адресом `http://127.0.0.1:17890/overlay/weapons`
   (1920×1080, галочки «Выключать источник…» и «Обновлять при активации сцены» — выкл).
6. Когда матч начался — **«Старт»** (или хоткей `F9`). Виджет показывает текущее оружие и
   два следующих. Килл назначенным оружием → автопереход, **после килла `F9` нажимать не
   нужно** (нажатие в течение 1,5 с после килла игнорируется, чтобы не проскочить оружие).
   `F9` — следующее вручную, `F8` — перекрутить текущее, `F7` — отменить последнее действие.
7. **«Пауза»** останавливает учёт киллов, очередь и статистика сохраняются; «Продолжить»
   (или `F9`) возобновляет. **«Сброс»** начинает всё заново.

8. **DPI-рулетка**: в разделе «DPI-рулетка» нажмите «Проверить мышь» (должно показать
   «PRO X 2», режим host и текущий DPI), добавьте в OBS источник «Браузер»
   `http://127.0.0.1:17890/overlay/dpi` (600×750). Дальше колесо крутится само после
   каждой смерти (пока жив — не крутится) или по хоткею `F6`. На виджете колесо видно
   только пока крутится, потом остаётся итоговое число; сегмент «Мой обычный DPI» выделен
   цветом. «Вернуть мой DPI» применяет это значение обратно.

Остановить утилиту — закрыть окно консоли. Состояние сессии сохраняется в `data/state.json`,
поэтому перезапуск утилиты или перезагрузка страницы в OBS ничего не теряют.

**Важно про права администратора.** Если Steam или CS2 запущены «от имени администратора»,
Windows не передаёт хоткеи обычным программам, пока игра в фокусе. Тогда запускайте `run.bat`
тоже от администратора (панель покажет предупреждение). Хоткеи ничего не внедряют в игру и
не шлют ей ввод — это та же механика, что у хоткеев OBS и Discord.

| `app/roulette.py` | очередь оружия, «мешок»/рандом, статистика, undo, сохранение |

| `app/main.py` | FastAPI: панель, оверлеи, SSE, `/gsi`, API |
| `app/templates/overlay_weapons.html` | виджет для OBS (прозрачный, силуэты, анимация конвейера) |

| `app/templates/panel.html` | панель управления |
| `app/modules/dpi/hidpp.py` | HID++ 2.0 клиент: фичи 0x0000/0x0005/0x8100/0x2202 через hidapi |
| `app/modules/dpi/backends.py` | HID++ backend, имитация для разработки, «none» |
| `app/modules/dpi/service.py` | DPI-рулетка: выбор значения, расписание применения, защита от отката G HUB |
| `app/modules/dpi/grid.py` | сетка допустимых DPI сенсора HERO 2 и округление |
| `app/templates/overlay_dpi.html` | колесо для OBS (canvas, серверный результат, доигрывает анимацию после перезагрузки) |
| `app/static/icons/` | официальные силуэты оружия CS2 (белые SVG) |

## Параметры виджета

Настройки задаются в панели, а параметры в URL их переопределяют (удобно для нескольких
источников в OBS):

```
/overlay/weapons?scale=1.3&layout=vertical&labels=1&color=ffffff&accent=ffd166&counter=0&align=center
/overlay/loadout?side=both&scale=0.8&names=0
/overlay/weapons?debug=1        — отладочная плашка со состоянием
```

## Сообщения в чат

Уведомления о старте гонки, новом оружии и новом DPI отправляет бот StreamElements по его
API (`POST /kappa/v2/bot/{channel}/say` с JWT-токеном канала из дашборда SE; канал берётся из
claims токена, проверка через `/channels/me`). Настраивается на вкладке «Общее», см.
QUICKSTART. JeetBot не имеет API для отправки сообщений извне.

## Как работает DPI-рулетка

Сервер выбирает значение и параметры анимации, виджет только проигрывает их, поэтому
перезагрузка источника в OBS посреди кручения всё равно покажет правильный итог. Применение
идёт к сенсору напрямую: фича HID++ `0x2202` (Extended Adjustable DPI), что требует host-режима
мыши (`0x8100`, G HUB: «On-Board Memory Mode» выключен). Значение округляется к сетке сенсора.
G HUB умеет возвращать DPI профиля при alt-tab/пробуждении мыши: фоновая защита перечитывает
DPI каждые 3 с и возвращает выбранное; закрепление профиля в G HUB (Settings → Persistent
Profile) убирает причину. Смерть определяется из GSI (здоровье 0 или переключение камеры на
тиммейта в живом раунде), в разминке не срабатывает. Подробности и варианты: `docs/DPI_PLAN.md`.

Если `hidapi` не установлен или мышь не найдена, остальное приложение работает как обычно.

## Как считаются киллы

GSI не сообщает, каким оружием сделан килл, поэтому используется эвристика: рост
`player.state.round_kills` в живом раунде, оружие — то, что было активно в предыдущем
пакете. Учитываются: наблюдение за тиммейтом после смерти (игнорируется), сброс в новом
раунде, разминка, мультикиллы, пропущенные пакеты (`previously`), недавно брошенные
HE/молотов (килл помечается «спорным» и не засчитывается в строгом режиме).
Режимы автоперехода: только назначенным оружием / любой килл / выключен.

Хоткеи не внедряются в процесс игры и ничего ей не отправляют; GSI — официальный механизм
Valve. Это безопасно для VAC. Сервер слушает только `127.0.0.1`, запросы с чужих сайтов
(cross-site) отклоняются.

## Разработка

```bash
./run.sh --no-browser          # macOS/Linux (без хоткеев)
.venv/bin/python -m pytest -q  # тесты
python tools/fetch_icons.py    # обновить иконки
build.bat                      # (Windows) собрать папку dist/cs2-roulette с exe
```

Иконки — собственность Valve; использование в личном стрим-оверлее соответствует
политике Valve по видео, но не распространяйте пакет иконок отдельно.

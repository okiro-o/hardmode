# Hardmode — инструкции для агента

Проект: стрим-тулза для CS2 на Python/FastAPI (гонка вооружений + DPI-рулетка + виджеты OBS + оверлей
поверх игры + вход в Twitch (награды за баллы, чат от аккаунта, прогнозы на матч) + статистика + донаты DonationAlerts/DonatePay со зрительской очередью).
Пользователь: русскоязычный стример, целевая платформа только Windows, разработка идёт на macOS без
реальной мыши и без Windows.

## Сначала прочитай
1. `docs/SPEC.md` — источник правды: архитектура, поведение, API, принятые и **отклонённые** решения,
   бэклог. Обновляй его при каждом значимом изменении (версия в шапке, нужный раздел).
2. `QUICKSTART.md` — пользовательская справка, она же вкладка «Справка» в панели. Правь вместе с UI.
3. Память агента для этой папки (`~/.claude/projects/-Users-prc-999-user-CS2/memory/`) — предпочтения
   пользователя и история решений.

## Как работать
- Тесты: `perl -e 'alarm 170; exec @ARGV' .venv/bin/python -m pytest -q tests` (на macOS нет `timeout`).
  Линт: `.venv/bin/python -m pyflakes app tests`. Оба должны быть чистыми перед коммитом.
- Живая проверка панели/виджетов: сервер `.venv/bin/python -m app --console --no-browser` на порту 17890
  (для встроенного браузера есть конфиг `.claude/launch.json`, имя `cs2-roulette`; он не в git).
  Переменные для разработки: `CS2R_DPI_BACKEND=fake` (имитация мыши), `CS2R_DATA=<папка>` (данные).
- Релиз = номер в `app/version.py` + коммит `vX.Y.Z: краткое описание` на русском + тег `vX.Y.Z` +
  `git push origin main --tags`. Пользователь обновляется через `git pull` на Windows. Архивы не нужны.
- Сообщения коммитов и ответы пользователю — по-русски. Коммиты заканчиваются строкой
  `Co-Authored-By: <модель> <noreply@anthropic.com>`.
- `*.bat` — UTF-8 с CRLF и `chcp 65001`; править только с сохранением CRLF (есть тест).
- `data/` (настройки, состояние, лог) в git не входит и не должна ломаться обновлением: новые поля
  настроек с дефолтами, старые ключи игнорируются или мигрируют.
- HTML-страницы отдаются без кэша; после правок виджетов пользователю нужно один раз обновить
  источник в OBS.

## Чего не делать
- Не возвращать отклонённое: хоткеи, авто-buy cfg, обучение лоадаута по покупкам, чтение лоадаута из
  игры (невозможно), длинные подсказки в блоках панели, подпись «твой обычный» у DPI (см. SPEC §9).
- Не убирать функциональность под видом чистки; не внедряться в процесс игры (только GSI и HID++).
- Не трогать `app/static/icons` (собственность Valve, вне лицензии проекта) и не менять лицензию
  (PolyForm Shield 1.0.0) без явной просьбы.
- Код Win32/HID++/PyInstaller на macOS не исполняется: менять осторожно, покрывать тестами с
  подменным транспортом и прямо говорить пользователю, что проверка только на его ПК.

## Что сейчас в очереди (детали в SPEC §10, §6d и памяти)
- Донаты сделаны в 0.18.0 (SPEC §6d), но ещё не проверены с реальными аккаунтами DonationAlerts/DonatePay:
  при первых отчётах пользователя сверять формат ответов и регистрацию приложения DA.
- Виджет очереди и команда `!очередь` сделаны в 0.19.0, оружие за баллы канала в 0.20.0, заявки вне лоадаута в конце очереди в 0.20.1, блок очереди поверх игры в 0.21.0. В 0.22.0 приложение само перезагружает свои виджеты в OBS при запуске (obs-websocket, SPEC §6e). В 0.23.0 необязательный вход в Twitch: свои награды с автовозвратом баллов и чат от аккаунта стримера (SPEC §6f; проверено только на поддельном API). В 0.24.0 по решению пользователя удалены StreamElements, «Определить»/ID наград и логин канала: баллы только через награды Hardmode «Добавить DPI в рулетку» / «Добавить оружие в очередь», чат только от аккаунта (не возвращать). В 0.21.1 удалено по решению пользователя: донатное действие «следующий DPI» (не возвращать), тумблеры «закрывать заявку киллом» и «подтверждать в чате» на вкладке DPI. В 0.27.0 оптимизация интерфейса: настроенные блоки сворачиваются в «Настроить», один блок «Поверх игры» с переключателем, чип связи только при обрыве; в 0.28.0 после одобрения по скриншотам: вкладка OBS — только ссылка и размер, Startup сворачивает зелёное в «Всё в порядке: N», «Настройки гонки» и «Когда писать» свёрнуты в строку. В 0.29.0 урон/ADR удалены целиком (CS2 их не шлёт; не возвращать), статистика перегруппирована, у карт победы и винрейт (проверено только на тестах). В 0.30.0 таблицы статистики через переключатель. В 0.31.0 прогнозы Twitch на матч (SPEC §6g; новый scope — старым входам нужен повторный вход; проверено только на поддельном API). В 0.32.0 G3SG1 и SCAR-20 в очереди — одна заявка по стороне. В 0.33.0 тумблер «Только оружие из лоадаута» для заявок зрителей. В 0.34.0 MVP — настоящие звёзды из GSI, лучший раунд «5k», в DM и гонке вооружений раунды не считаются. В 0.35.0 `run-gsi-record.bat` пишет настоящие пакеты в data/gsi-record.jsonl: когда пользователь пришлёт файл — сверить match_end/match_start/mvp/раунды DM и сделать фикстуры. В 0.36.0 обновление из панели (`app/updater.py`: git pull + перезапуск через run.bat; перезапуск на Windows не проверен вживую). Спорные изменения UI сначала показывать скриншотами «было/стало». Отложено пользователем: челлендж-раунды (в т.ч.
  ноускоуп через захват экрана), голосование чата, серии/штрафы, `!dpi`, вебсокеты донатов, звуки, автостарт гонки.
